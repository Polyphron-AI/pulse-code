# Pulse Code product requirements

This directory is the product authority for Pulse Code requirements. Pulse Code is a downstream
product that may selectively adopt released T3 features while maintaining an independent desktop
distribution. The integration program starts with a provider-neutral platform and uses the native
Pulse Issues work as its reference adapter.

## Requirement set

- [Pulse integrations](10-pulse-integrations.md) — strategy, experience, platform, safety, metrics,
  and rollout.
- [Product-line and distribution boundary](11-product-line-and-distribution-boundary.md) — upstream
  fidelity, downstream selectivity, desktop identity isolation, and shared-client scope.
- [Integration foundation acceptance criteria](20-acceptance-criteria/integration-foundation.md) —
  testable first-release contract.
- [Desktop product-line boundary acceptance criteria](20-acceptance-criteria/desktop-product-line-boundary.md)
  — testable side-by-side, release-source, state-isolation, and import requirements.
- [Change requests](change-requests/) — proposed PRD changes and sign-off history.
