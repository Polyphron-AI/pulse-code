Contract surface

Typed transport, deliberate mutation

Read methods require orchestration read scope. Lifecycle mutation, preview, and confirmation require operate scope.

Lifecycle

Connections and mappings

listConnections, disconnect, setProjectMapping, and removeProjectMapping.

Bounded action

Issue context and status

issueContext, issuePreviewStatus, and issueConfirmStatus.

  • Pending previews are session-scoped, expire, and bind the expected Issue version.
  • Reconnect invalidates pending previews; confirmation returns a typed audit receipt.
  • Confirmation refreshes only the owning environment’s connection and Issue context.
  • Native issues.* RPCs remain unchanged beside the additive methods.

Open gates

Durable authorization release

Host isolation, redirect replay, diagnostics, backups, revocation, and shared-server ownership remain unresolved.

Definition needed

Tokenizer

Define what “tokenizer” means for this roadmap and name its authoritative source before implementation claims.

Discovery

Later providers

Externally managed credentials and measured provider demand must precede a bounded GitHub work adapter.
