Decision record · 20 August 2026

Rename the product. Keep its identity.

Pulse Code gets a durable, server-owned link to Pulse without turning a visible rename into a new mobile app—or treating a technically verified bridge as an OAuth release.

Ⅱ
Release gate OAuth and general release held

What changed

Product-facing names become Pulse Code. The integration gains typed server, client, mobile, context, action, and compatibility paths.

What stayed stable

Installed-app identity, t3code links, package scope, storage aliases, native issues.* RPCs, and persisted Issue/thread IDs.

What remains gated

Global SSO, OAuth release, shared-server ownership, revocation guarantees, externally managed credentials, tokenizer definition, and later providers.
