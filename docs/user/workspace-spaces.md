# Office and Code workspaces

Use Office and Code below the Pulse wordmark to switch spaces. Code keeps your projects, threads, search and scheduled work. Office opens your meetings, calendar and email workspace, with Communications in its sidebar.

Switching back from Office restores the previous Code location for this app session. If there is no previous location, Code opens your usual landing page.

In the Windows desktop app, Office supports connected calendar and email accounts and local Pulse Talk recording and transcription. These accounts and recordings stay on that computer; remote web connections show their availability instead of accessing them.

Local Talk recording and transcription require a desktop build that includes the native Talk worker. Office shows when the worker is unavailable. This does not affect Code dictation.

Communications is an interactive concept using sample conversations. It does not connect to live email, Discord, Slack or Telegram accounts. Messages and saved items in this view last until you leave it.
