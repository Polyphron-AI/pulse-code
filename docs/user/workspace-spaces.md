# Office and Code workspaces

Use Office and Code below the Pulse wordmark to switch spaces. Code keeps your projects, threads, search and scheduled work. The Workspace entry opens the cross-project overview with work that needs attention first.

Switching back from Office restores the previous Code location for this app session. If there is no previous location, Code opens its workspace overview. Switching spaces does not start a new coding thread.

Office currently previews where meetings, calendar and email integrations will live. Its services are not connected yet. The preview does not request microphone access or read mail, recordings or calendar events. Existing coding functionality remains available in Code.
