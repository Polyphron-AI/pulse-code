# Saved session outputs

Completed assistant messages can include links to reports, spreadsheets, images and other files. Pulse saves copies on the environment where the thread ran. Use the download button beside a file link to download its saved version. On mobile, choose **Download saved output** to download or share it.

The first saved copy belongs to that message. Later changes to the original file do not change it. A later message linking the same filename gets its own copy. Saved copies remain available after deleting the original file or removing its worktree.

HTML reports with local stylesheets, images or fonts download as ZIP archives. Extract the ZIP before opening the report. External websites and files outside the report's folder are not included. Keep supporting assets with the report or export a self-contained file.

Saved files support up to 64 MB each, 128 supporting files per report, and automatic capture of up to 32 linked files and 128 MB per message. Capture runs in the background. A file that is missing, still changing, too large or unreadable cannot be saved. Opening its link shows the reason and recovery action. Older messages can save a copy on first access if the original still exists; that copy reflects the file at that time.

Previews and downloads use the thread's source environment. Refreshing a saved preview obtains fresh access. If a restored browser tab shows an expired page, use the preview's Refresh button or reopen the message link. An offline environment must reconnect before an unsaved download can be fetched. Download copies you need while offline.

Source editing remains separate from saved output downloads. Opening a source file in an editor uses the thread's environment. Saved outputs are retained in that environment's Pulse data; this release does not synchronize them to cloud storage or automatically expire saved copies.
