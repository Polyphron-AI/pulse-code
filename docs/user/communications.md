# Communications concept

Open **Office → Communications** to try the unified conversation view.

Browse sample Discord channels, Telegram groups, email conversations, and direct messages. Open replies in the thread panel, add sample messages, react, or save a message to **Later**. Search finds conversations by name or message text.

This is an interactive concept. No accounts are connected, and messages are never sent to an external service. Sample messages, reactions, and saved items reset when you leave the view or reload Pulse.

Use **Code** to return to your coding workspace. Meetings, Calendar, and Email remain available in Office.
