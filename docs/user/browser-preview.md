# Browser preview and recording

Browser previews can stay in the side panel or a floating player. When an agent uses a browser,
Pulse Code keeps its floating preview available. Opening the same tab in the side panel hides the
duplicate player; closing the panel lets the player appear again. Configure automatic floating
previews in **Settings ? Integrations**.

Browser recordings use 30 fps by default. In **Settings ? Integrations**, choose **Browser recording
frame rate** to use 60 fps for smoother motion. Higher frame rates use more CPU and storage.
Inactive previews stop rendering unless recording, picture-in-picture, or agent activity needs them.

If a selected element's screenshot cannot be captured, Pulse Code keeps the annotation without the
image and reports the capture failure. You can continue composing or send the annotation.
