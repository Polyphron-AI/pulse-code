# Desktop quit shortcut

In General settings, choose how Cmd+Q on macOS or Ctrl+Q on Windows and Linux quits Pulse Code:

- **Direct:** one press quits.
- **Hold:** hold the shortcut until the window disappears, then release it. A quick second press also quits.
- **Double press:** press the shortcut twice within half a second.

Hold is the default. If you previously turned quit confirmation off, your setting becomes Direct. The application menu's Quit action and ordinary window-close behavior keep their existing behavior.

Hold uses keyboard repeat to confirm that the keys are still pressed. If repeat is disabled, use a double press or the application menu. On Linux, the window can remain visible until you release the shortcut.
