# Opening linked files on mobile

When a chat message links to a file in the current project, tap the link and
choose how to open it:

- **Preview in Pulse Code** opens the file in the built-in project file viewer.
- **Download file** downloads a copy from the thread's connected environment and
  opens the native save/share sheet. Choose Save to Files on iOS or a file-saving
  app or folder on Android to keep it on your device.

Downloads work for local and remote environments while they are connected. The
temporary copy is stored in the app cache and may be removed automatically by the
operating system. If the file or environment is unavailable, Pulse Code keeps the
chat open and shows an error.

Excel workbooks, Word documents, archives, and other binary files offer a download
instead of trying to display them as text. Markdown and source files keep their
previews and can also be downloaded from the viewer's File actions menu.

On desktop or web, right-click a linked file or a tagged file in the composer and
choose **Download file**. The file viewer also has a Download file button. Desktop
saves to your Downloads folder and adds a number when the filename already exists.
Web downloads follow your browser's download settings. The file comes from the
thread's environment, even when you are using another device.
