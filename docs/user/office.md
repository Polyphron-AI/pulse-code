# Office alpha

Open **Office** from the sidebar or search for **Open Office** in the command palette. Use the Office, Mail, and Code navigation to move between your overview, mailbox, and coding work.

Office and Mail use the full workspace width. The project sidebar appears when you return to Code, with its previous size and open state preserved.

Office uses the selected Pulse environment. It shows email accounts, your five most recently saved drafts, and send operations that need attention or confirmation. Select a draft to open it with its original account. Outbox links are grouped by account so you can check the correct sending history before retrying anything.

Enable Mail alpha, then open the mailbox to enable Mail on the environment and connect an account. IMAP receives mail; SMTP configures sending. Accounts with incomplete sending setup are labelled. Saved drafts and send history remain available when Mail is disabled.

The mailbox has folder navigation, a message list, and a reading pane. On smaller screens, open a message to focus on reading and use Back to return to the list. Search and filters apply to the selected folder. Folder icons follow the provider's folder roles, including Sent folders with localized names.

Tags and linked context appear with each message. Stored suggested links are labelled and remain until changed or removed. Automatic discovery is not available in this alpha. Saving a project reference does not start coding work.

Calendar, Meetings, universal Tasks, SOPs, Relationships, and Explorer are shown as planned Office spaces. Their descriptions explain their intended use; they do not contain sample records or working services yet. Native mobile retains its existing Mail screens; this Office overview is available in the web and desktop clients.

An accepted send result means the provider accepted submission. Check the result details for Sent-copy problems or uncertain outcomes before sending another copy.
