# Copying chat tables

In the web and desktop apps, open the copy menu below a chat table and choose:

- **Copy as Markdown** for Markdown documents and messages.
- **Copy as CSV** for spreadsheets and data tools.
- **Copy as HTML** for pasting a formatted table into an editor that accepts rich text. In browsers without rich clipboard support, this copies HTML source instead.
- **Copy as PNG** for pasting a table image into documents, messages, or slides.

HTML and PNG exports use a light background and include the complete cell text, even when the chat view truncates it. Images inside cells are represented by their descriptions.

PNG copying requires browser support for image clipboard writes. If clipboard access is unavailable, use a secure connection and try again. Very large tables may exceed image limits; copy them as HTML instead.
