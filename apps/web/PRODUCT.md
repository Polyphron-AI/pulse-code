# Pulse

<!-- impeccable:product-schema 1 -->

## Platform

web. The Electron desktop app wraps this client. React Native mobile has its own screens.

## Users and purpose

People managing operational and coding work across email, accounts, procedures, and directory-based projects. Office brings that operational context together; Code retains project and thread tools. The user confirmed these jobs in the Pulse product discussion and PRD.

## Product commitments

- Familiar, predictable daily mailbox interactions, with receiving and sending. Sent copies belong in the provider's Sent folder and synchronize across devices.
- Projects remain directory/Git based. Linking a repository does not start coding work.
- Tasks are shared outcomes across Office and Code. Never invent separate view-specific copies.
- Suggested links persist until edited or removed. New people and organisations require confirmation.
- Use connected account information only. No public-web discovery.
- Preserve remote access, environment ownership, keyboard operation, and responsive layouts.
- Alpha activation and available server capabilities determine what works. Unavailable capabilities must not present invented data or successful actions.

## Evidence and scope

The Pulse workspace PRD in the main checkout records the full target. This worktree has real mail contracts, server operations, saved drafts, send receipts, and clients. Calendar, universal Tasks, SOP execution, and automated discovery are not implemented by this UI extension.

## Brand commitment

The user requests a familiar Outlook-style mailbox and Impeccable for UI work. Extend Pulse's existing components, typography, themes, and navigation. Keep the interface simple and predictable.
